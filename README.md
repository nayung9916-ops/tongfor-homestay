# ระบบจัดการห้องพัก - โฮมสเตย์ ตองฟอร์ (Tongfor Homestay PMS)

ระบบจอจัดการห้องพักและปฏิทิน 3 ห้อง (101, 102, 103) สำหรับแก้ไขปัญหาปฏิทินไม่ตรงกัน และป้องกันปัญหาห้องชนกัน (Overbooking) ระหว่าง **Agoda** และ **Facebook / จองตรง**

---

## วิธีเปิดใช้งาน

1. ดับเบิลคลิกที่ไฟล์ **`start.bat`**
2. ระบบจะเปิดหน้าจอ Dashboard บนเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`
3. *(ห้ามปิดหน้าต่างดำของ start.bat ขณะกำลังใช้งานระบบ)*

---

## วิธีเชื่อมต่อ Two-Way iCal กับ Agoda

### 1. ขาเข้า (ดึงวันจองจาก Agoda มาแสดงในระบบ)
- ในหน้าแดชบอร์ด กดปุ่ม **"⚙️" (รูปฟันเฟือง)** ด้านบนขวา
- วางลิงก์ iCal Export จาก Agoda YCS ของแต่ละห้อง
- กด **"บันทึกการตั้งค่า"** ระบบจะดึงวันจองจาก Agoda มาขึ้นแถบสีแดงในตารางให้อัตโนมัติ

### 2. ขาออก (ส่งวันจองจาก Facebook ไปปิดห้องใน Agoda)
- ในหน้าต่างตั้งค่า (รูปฟันเฟือง) จะมี **"ลิงก์ iCal ส่งออก"** ของแต่ละห้อง เช่น:
  - ห้อง 101: `http://localhost:3000/api/ical/101.ics`
  - ห้อง 102: `http://localhost:3000/api/ical/102.ics`
  - ห้อง 103: `http://localhost:3000/api/ical/103.ics`
- กดปุ่ม **"คัดลอก"**
- ไปที่ **Agoda YCS > Calendar Sync > กด "Import Calendar"** แล้ววางลิงก์ลงไป
- เมื่อคุณกดบันทึกการจอง Facebook ในระบบนี้ Agoda จะนำไปปิดห้องให้อัตโนมัติ

---

## โครงสร้างโฟลเดอร์
- `data/database.json`: ไฟล์ฐานข้อมูลห้องพักและประวัติการจอง
- `public/index.html`: หน้าจอแดชบอร์ด
- `server.ps1`: ตัวจัดการระบบและตัวเชื่อมต่อ Agoda
- `start.bat`: สคริปต์เปิดระบบคลิกเดียว
